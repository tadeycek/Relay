**The negative tests matter:** Opus comfort noise can produce nonzero PCM even when a sender feeds silence. In the
parent mutation run silent Android still produced 403 incoming packets at Linux, but its sample-energy assertion
rejected it; silent Linux similarly gave Android RTP packets and 2,312 nonzero samples, but Android reported
`android_receive=FAIL`. Presence of packets/nonzero samples alone would have been a false success. The suite
requires an RMS >500 on both sides and checks which exact receiver rejected the silent source.

## Isolation / cleanup

Media is native WebRTC Opus/DTLS-SRTP across one Android and one Linux endpoint. SDP/ICE travels through a bounded
loopback signalling bridge and an owned adb reverse mapping, **not a PCM proxy**. Android's AudioRecord is disabled
before factory creation, source PCM is generated by the SDK callback, its speaker is muted, and Linux is headless.
There is no RECORD_AUDIO permission, microphone capture, physical listening or echo-cancellation evidence.

Only standalone package `org.relay.callsprobe` is installed; actual Relay app is not altered by WP02. No public
STUN, TURN, SFU, credentials, firewall or provider-account setting is used. Raw native diagnostics remain ignored
in `.private/`; committed evidence has numeric metrics and fixed-status messages only.

Parent verified no remaining reverse mapping and no probe PID on emulator-5556, then shut down its owned emulator
with `adb ... emu kill`. Background emulators have a per-terminal memory budget: prior interrupted runs are retained
in the delegate snapshot and not counted as passes. No long-duration stability claim follows from this test.
