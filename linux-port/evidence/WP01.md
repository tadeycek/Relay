## Corrections found while exercising it

- Rust SDK and OkHttp both export `Request`/`Response`; qualified OkHttp references fix ambiguous compilation.
- Android Java source includes do not constrain Kotlin compilation as assumed; a Gradle Sync task now copies only
  the production payload codec into generated sources rather than accidentally compiling the entire app.
- AGP 8.7.3 warns that compileSdk 36 exceeds its tested API 35. The isolated APK compiled and ran on API 36; this
  warning remains visible rather than being suppressed. No production build-tool version was changed.
